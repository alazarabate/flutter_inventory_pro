# Offline-First Inventory System

Demo: https://youtube.com/shorts/YbgSNog6kVA?feature=share

## Features
✅ Offline-first architecture (Hive + Firebase)
✅ Two-way sync between apps (Tested on 2 devices)
✅ Camera + Firebase Storage integration
✅ PDF reports + WhatsApp share
✅ Conflict resolution (last-write-wins)
✅ Search with debounce

## Tech Stack
Flutter | Firebase | Hive | Riverpod | Dart

## How to Test
1. Download App A APK: https://drive.google.com/file/d/1cD778DTvBv-NmKRQGvERfuqj1KZ3iKim/view?usp=drive_link
2. Download App B APK: https://drive.google.com/file/d/15HNpxpfE70MNLjRqC6eK69YzHiSq6QtZ/view?usp=drive_link
3. Install both on your phone
4. Add product in App A → App B shows it instantly
5. Works offline → syncs when online
